Customer Churn Analysis in Power BI
This project leverages Power BI Desktop to help businesses reduce customer churn by identifying trends, patterns, and actionable insights.

📊 Key Features
Predictive Churn Modeling: Identify at-risk customers to enable proactive retention strategies.
Customer Segmentation: Group customers based on usage, payment methods, and subscription plans for targeted marketing.
Data Insights Visualization: Present trends and insights in an interactive and easy-to-understand manner.

📂 Project Files
Power BI File (.pbix): Download the full Power BI file.
Dataset: Data extracted from an example telecom dataset, anonymized for demonstration purposes.

🚀 Insights Gained
High Churn Among Specific Segments:

Customers with no unlimited data plan showed higher churn rates.
Monthly contract customers were more likely to churn than yearly contract customers.
Regional Trends:

Certain states showed significantly higher churn rates, suggesting regional interventions.
Customer Support Impact:

States with higher average customer service calls also exhibited higher churn rates, indicating potential dissatisfaction.

🛠 Tools Used
Power BI Desktop

📖 Steps to Reproduce
Download the .pbix file and open it in Power BI Desktop.
Use the built-in visuals to explore customer churn patterns and customize as needed.

Contract Type
Payment Method
Geography
